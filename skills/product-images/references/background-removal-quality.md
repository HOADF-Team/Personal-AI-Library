# Контроль качества удаления фона на фото одежды

## Правильный порядок

1. Сохранить исходное изображение без изменений.
2. Проверить ориентацию, размер, цветовой профиль и наличие прозрачного канала.
3. Выполнить сегментацию/удаление фона выбранной моделью.
4. Проверить alpha mask, а не только RGB-превью на белом фоне.
5. Просмотреть края при увеличении: рукава, тонкие лямки, бахрому, волосы/нитки, промежутки между деталями, складки и тёмные участки на тёмном фоне.
6. Проверить ореолы, вырезанные части товара, остатки старого фона и чрезмерное сглаживание.
7. Сохранить результат в PNG с альфа-каналом; JPEG не хранит прозрачность.
8. Сравнить исходник и результат рядом, затем проверить финальный фон и экспортный размер.

## Почему фон может остаться

- Модель воспринимает цветной/контрастный участок как часть объекта.
- Штанины, рукава или предметы на вешалке сливаются с фоном.
- Тени и складки образуют неоднозначную границу.
- Порог alpha слишком мягкий либо маска не очищена.
- Модель обучена на другом типе объектов или композиции.

## Исправление по возрастанию вмешательства

1. Улучшить исходное фото: отделить вещь от фона, добавить равномерный свет и контраст.
2. Повторить сегментацию с подходящей моделью/параметрами.
3. Исправить маску локально: закрыть дырки внутри ткани, удалить фоновые островки, уточнить края.
4. Для сложных участков применить ручную маску/кисть или второй сегментатор.
5. Если автоматическая маска всё ещё портит изделие, не выдавать её за готовый результат — оставить пометки или запросить исходник лучше.

## Python: быстрая проверка PNG

```python
from PIL import Image

image = Image.open("result.png")
print("mode:", image.mode)
print("size:", image.size)

if "A" not in image.getbands():
    raise ValueError("В изображении нет alpha-канала")

alpha = image.getchannel("A")
print("alpha extrema:", alpha.getextrema())
print("transparent pixels:", sum(1 for value in alpha.getdata() if value == 0))
```

Эта проверка подтверждает наличие альфа-канала, но не качество маски. Визуальный контроль обязателен.
