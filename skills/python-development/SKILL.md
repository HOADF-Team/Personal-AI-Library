# Python development

1. Сначала изучи существующий проект: структуру, точку входа, зависимости, конфигурацию и стиль кода.
2. Уточни фактическую версию Python и используемое окружение, если это влияет на решение.
3. Исправляй первопричину ошибки, а не маскируй её общими обработчиками исключений.
4. Сохраняй публичные интерфейсы и совместимость, если пользователь не просил обратного.
5. Не добавляй зависимости, если задачу можно решить стандартной библиотекой.
6. Для внешних пакетов указывай, зачем они нужны и как установить их воспроизводимо.
7. Добавляй проверку входных данных, понятные сообщения об ошибках и корректное логирование.
8. Не помещай секреты в исходники и примеры конфигурации.
9. После изменений запускай подходящие тесты или минимальные проверки. Не утверждай, что проверка прошла, если она не запускалась.
10. Для больших задач работай небольшими этапами и показывай конкретные изменённые файлы.
