# Documents and Office files

1. Определи формат, назначение документа, аудиторию и требования к редактируемости.
2. Если пользователь передал существующий файл, сначала изучи его содержимое и структуру; не пересоздавай документ по фрагменту.
3. Сохраняй исходный файл отдельно и не перезаписывай его без разрешения.
4. Для таблиц проверяй формулы, типы данных, листы, диапазоны и форматирование.
5. Для PDF проверяй извлечение текста, страницы, таблицы и изображения; при сканах используй OCR/визуальный контроль.
6. Для презентаций проверяй последовательность, читаемость, переполнение и единообразие слайдов.
7. Используй библиотеки, соответствующие формату; не подменяй формат расширением файла.
8. После генерации повторно открой файл и проверь его содержимое и структуру.
9. Указывай ограничения конвертации, OCR и возможные потери форматирования.
10. Не придумывай данные, подписи, суммы и источники.

## Локальная методика
Используй [office-file-workflow.md](references/office-file-workflow.md) для выбора формата, создания и проверки результата.

## Проверка
Для таблиц — контроль формул и итогов; для DOCX/PPTX — проверка структуры и рендеринга; для PDF — просмотр страниц и проверка извлечённого текста. Не считать файл корректным только потому, что он сохранился.
