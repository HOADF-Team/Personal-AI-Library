# Подготовка публикаций под разные площадки

## Перед написанием

Зафиксировать цель, аудиторию, факт/событие, доказательство, ссылку и желаемое действие. Один пост — одна главная мысль. Не писать «новость» без подтверждения, что изменилось.

## Telegram

Структура: заголовок по сути → контекст → конкретный результат/наблюдение → доказательство или ссылка → вопрос/CTA при необходимости. Использовать короткие абзацы. Не перегружать эмодзи и хэштегами.

## X

Одна сильная мысль в первом сообщении. Затем факты и краткое объяснение. Тред использовать только если есть последовательность, которую нельзя уместить в один пост. Не дробить один абзац искусственно ради количества сообщений.

## GitHub

Для изменений проекта выбирать подходящий формат: README для назначения и запуска, changelog/release notes для версий, issue для конкретной задачи, discussion для обсуждения. Не использовать рекламные формулировки вместо технической информации.

## Медиа, согласия и раскрытия

- Проверить лицензию/права на фото, видео, музыку, иллюстрации и скриншоты; публичная доступность не означает разрешение на повторную публикацию.
- Для узнаваемых людей и частных историй проверить разрешение и применимое правовое основание; для несовершеннолетних применять повышенную осторожность и не публиковать, если согласие/основание неясно.
- Удалить из медиа лишние персональные сведения: адреса, номера документов, контакты, приватные экраны, токены, QR-коды доступа и GPS EXIF.
- Не выдавать AI-сгенерированные отзывы, изображения людей, фотографии товара или события за реальные. Если синтетический контент, реклама, спонсорство или партнёрство требует маркировки, проверить актуальные правила платформы и применимые требования перед публикацией.
- Не использовать цитату, логотип, музыку или пользовательский контент только на основании того, что они доступны в интернете.

## Проверка перед отправкой

- Факты и цифры подтверждены.
- Скриншоты не раскрывают секреты и личные данные.
- Есть право на использование всех медиа и цитат.
- Функции существуют в текущей версии.
- Ссылки открываются и ведут на ожидаемые адреса.
- Текст соответствует актуальным правилам площадки.
- Публикация остаётся черновиком до явного подтверждения пользователя.

## Повторное использование

Одно событие можно адаптировать для разных площадок: менять длину, контекст и CTA, но не факты. Не копировать пост дословно во все каналы.
