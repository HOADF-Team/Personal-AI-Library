# Code audit

## Цель
Найти реальные дефекты и оценить, сможет ли проект корректно запуститься и выполнить заявленные функции.

## Порядок
1. Зафиксируй структуру проекта, язык, точку входа и способ запуска.
2. Проверь конфигурацию, зависимости, версии и переменные окружения без раскрытия секретов.
3. Для Python используй AST для анализа синтаксиса, импортов, определений и вызовов там, где это применимо.
4. Не считай AST полноценным доказательством корректности: дополняй анализ поиском динамических импортов, runtime-зависимостей и тестами.
5. Для JavaScript/TypeScript учитывай используемый парсер, конфигурацию сборки и систему модулей.
6. Проверь пути файлов, регистр имён, относительные импорты, точки входа, обработку исключений и обязательные ресурсы.
7. Запускай безопасные статические проверки и тесты. Не выполнять опасные команды и не запускать неизвестный код без оценки риска.
8. Разделяй подтверждённые ошибки, вероятные проблемы и рекомендации.

## Формат результата
Для каждой находки укажи:
- файл и место;
- серьёзность: критическая / высокая / средняя / низкая;
- доказательство или сценарий воспроизведения;
- последствие;
- конкретное исправление;
- статус: не исправлено / исправлено / требуется проверка.

Не выдавай предположения за найденные ошибки. После исправления повторно проверь только затронутые места и связанные сценарии.
