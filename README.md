# Personal AI Library

**Personal AI Library** — библиотека готовых навыков (Skills), инструкций и рабочих методик для Codex. Она помогает агенту быстрее переходить от общей задачи к конкретному проверенному процессу: диагностике, аудиту, разработке, настройке или подготовке результата.

Библиотека рассчитана на повторное использование в разных проектах. Вместо того чтобы каждый раз собирать порядок действий с нуля, Codex выбирает подходящий навык и при необходимости читает его дополнительные материалы.

> Сейчас в репозитории 23 навыка. Коллекция развивается; наличие инструкции не означает, что каждый описанный процесс проверен на всех возможных проектах и конфигурациях.

## Что входит в библиотеку

Каждый навык находится в отдельной папке `skills/<name>/` и обычно содержит:

- `SKILL.md` — краткое описание задачи, условия выбора навыка и основные правила работы.
- `references/` — подробные runbooks, чек-листы, алгоритмы, шаблоны и справочные материалы.
- `scripts/` — вспомогательные скрипты, если автоматизация действительно полезна.

Дополнительные материалы загружаются по мере необходимости. Это позволяет не передавать агенту весь объём документации при каждой задаче.

## Установка на Windows

**Требования:** Windows 10/11 и Windows PowerShell 5.1 или PowerShell 7. Для установки Python не требуется.

1. Откройте страницу репозитория: https://github.com/HOADF/Personal-AI-Library
2. Нажмите **Code → Download ZIP** и распакуйте архив.
3. Откройте PowerShell в распакованной папке.
4. Выполните команды:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\install.ps1
```

Навыки будут скопированы в пользовательскую папку:

```text
%USERPROFILE%\.agents\skills\
```

После установки перезапустите Codex, если он уже был открыт.

### Обновление

Скачайте свежую версию репозитория, распакуйте её и запустите в новой папке:

```powershell
.\install.ps1 -Force
```

Без параметра `-Force` установщик пропускает уже существующие папки навыков. С параметром `-Force` он обновляет совпадающие файлы из библиотеки, но не удаляет дополнительные пользовательские файлы в папках назначения.

### Безопасность установщика

`install.ps1` копирует файлы навыков в указанную папку. Он не устанавливает Python-пакеты, не подключается к API, не запускает скрипты из навыков и не требует токенов или паролей.

Перед запуском всё равно можно просмотреть содержимое установщика и самих навыков.

## Проверка и тесты

Для проверки структуры библиотеки нужен Python 3.9 или новее. Дополнительные пакеты для основной проверки не требуются:

```powershell
python .\validate_skills.py
```

Запуск модульных тестов:

```powershell
python -m unittest discover -s tests -v
```

Проверка установщика в Windows PowerShell:

```powershell
.\tests\test_install.ps1
```

GitHub Actions автоматически проверяет структуру и тесты при push и pull request. Workflow проверяет установщик в Windows PowerShell 5.1 и PowerShell 7.

Проверки подтверждают корректность структуры, локальных ссылок, синтаксиса проверяемых Python-файлов и поведения установщика в тестовых сценариях. Они **не доказывают**, что каждая методика подходит для любого проекта, что все внешние сервисы доступны или что результат работы агента всегда будет правильным.

## Принципы проекта

- **Практичность:** навыки должны помогать выполнять реальные задачи, а не увеличивать коллекцию ради количества.
- **Точность:** факты, предположения и непроверенные сведения должны быть разделены.
- **Пошаговая работа:** сначала анализ ситуации, затем план и только после этого изменения.
- **Безопасность:** не публиковать секреты; не выполнять необратимые действия без разрешения.
- **Контроль расходов:** не подключать платные API и сервисы без согласования.
- **Проверка сторонних материалов:** перед использованием проверять источник, лицензию, зависимости, скрипты и совместимость.
- **Прозрачность:** фиксировать источники и ограничения; не заявлять о тестах, которые фактически не проводились.

Общие правила для агента находятся в [AGENTS.md](AGENTS.md). Источники и заметки о проверке сторонних материалов — в [SOURCES.md](SOURCES.md).
