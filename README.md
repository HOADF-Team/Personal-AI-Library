# Personal AI Library

Персональная библиотека инструкций и навыков для Codex.

## Установка на Windows

1. Скачайте репозиторий: **Code → Download ZIP**.
2. Распакуйте архив.
3. Откройте PowerShell в папке репозитория.
4. Выполните:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\install.ps1
```

Навыки будут установлены в глобальную папку `$HOME\.agents\skills` и станут доступны в разных проектах Codex.

Чтобы обновить уже установленные навыки:

```powershell
.\install.ps1 -Force
```

## Структура

- `AGENTS.md` — общие правила работы агента в этом репозитории.
- `skills/<name>/SKILL.md` — отдельные специализированные навыки.
- `install.ps1` — установщик навыков для Windows.
- `CATALOG.md` — список направлений и статусы.

## Принципы

- Один навык — одна область работы.
- Используются только навыки, подходящие к текущей задаче.
- Факты отделяются от предположений.
- Платные API и сервисы не подключаются без согласования.
- Пароли, токены и API-ключи в библиотеку не добавляются.
- Сторонние навыки проверяются на источник, лицензию, безопасность, зависимости и совместимость.

Первоначальный набор — собственные базовые инструкции. Сторонние навыки будут добавляться после проверки с указанием оригинального источника и лицензии.
