# Personal AI Library

Персональная библиотека инструкций и навыков для Codex.

## Установка на Windows

1. Скачайте репозиторий: **Code → Download ZIP**.
2. Распакуйте архив.
3. Откройте PowerShell в распакованной папке.
4. Выполните:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\\install.ps1
```

Навыки будут скопированы в глобальную папку `$HOME\\.agents\\skills` и станут доступны из разных проектов Codex.

Чтобы обновить уже установленные навыки:

```powershell
.\\install.ps1 -Force
```

Параметр `-Force` заменяет существующие одноимённые папки навыков их версиями из этой библиотеки. Пользовательские изменения внутри таких папок будут перезаписаны.

## Проверка библиотеки

Нужен Python 3.9+ без дополнительных пакетов:

```powershell
python .\\validate_skills.py
```

## Структура

- `AGENTS.md` — общие правила работы в этом репозитории.
- `skills/<name>/SKILL.md` — специализированные навыки.
- `install.ps1` — установка навыков в профиль пользователя Windows.
- `validate_skills.py` — проверка метаданных и структуры навыков.
- `CATALOG.md` — каталог направлений.
- `SOURCES.md` — проверенные источники и решения по включению.

## Принципы

- Один навык — одна область работы.
- Агент должен выбирать только навыки, подходящие к задаче.
- Факты отделяются от предположений.
- Платные API и сервисы не подключаются без согласования.
- Пароли, токены и API-ключи в библиотеку не добавляются.
- Сторонние навыки проверяются на источник, лицензию, безопасность, зависимости и совместимость.
- Наличие навыка само по себе не даёт доступ к бирже, соцсети, аккаунту или API.

Сейчас в библиотеке 21 навык. Коллекция будет расширяться после проверки новых направлений и качества инструкций.
