# Contributing / Участие в развитии

Read [FEEDBACK.md](FEEDBACK.md) before reporting a skill defect. Search existing issues, provide minimal sanitized evidence, and distinguish observed behavior from hypotheses. Never publish secrets or private project data. Sensitive security reports require a private channel agreed with the maintainer.

Propose focused changes through a pull request, preserve licenses, add regression tests or reproducible scenarios where applicable, update the changelog and wait for all required checks. Maintainers verify the fix before closing the issue.

Перед обращением прочитайте [FEEDBACK.md](FEEDBACK.md). Проверяйте дубликаты, не раскрывайте закрытые данные. Исправления оформляйте через Pull Request с проверками, описанием результата и ограничений. Не считайте успешный CI доказательством качества всех ответов ИИ.
