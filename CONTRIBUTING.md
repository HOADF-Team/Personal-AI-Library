# Contributing / Участие в развитии

Follow [FEEDBACK.md](FEEDBACK.md) for reports. / Следуйте правилам обратной связи.

Maintainers triage reports as confirmed, suspected, environment-specific, agent error or duplicate. Reproduce confirmed defects using synthetic data; record evidence and limitations in the evaluation log. Make minimal fixes on a separate branch, add regression coverage where feasible, update CHANGELOG.md and submit a pull request. Require all CI checks; follow [RELEASING.md](RELEASING.md). Close issues only with evidence of resolution or an explicit reason. Do not treat passing structural checks as proof of model behavior.

Сопровождающие классифицируют замечания, воспроизводят дефекты на искусственных данных, фиксируют доказательства и ограничения, вносят минимальные исправления в отдельной ветке, добавляют регрессионные проверки при возможности и обновляют журнал изменений. Слияние только после CI; закрытие обращения — с доказательством исправления или объяснением. Успешная структурная проверка не доказывает правильность поведения ИИ.

Respect repository licenses and third-party rights. / Соблюдайте лицензии репозитория и права третьих лиц.
